# Aventura Escolar CR — sitio promocional

Landing estática para presentar Aventura Escolar CR, sus simuladores, juegos educativos, laboratorio de IA, video, entrevista y enlaces oficiales de descarga.

## Publicación en GitHub Pages

1. Cree un repositorio en GitHub y agregue su URL remota con `git remote add origin <URL_DEL_REPOSITORIO>`.
2. En GitHub, abra **Settings → Pages** y elija publicar desde la rama principal y la carpeta raíz.
3. Cuando obtenga la URL pública, sustituya `https://TU-DOMINIO.com/` en `robots.txt` y `sitemap.xml` por la URL definitiva.
4. Registre esa URL en Google Search Console, verifique la propiedad y envíe `https://su-dominio/sitemap.xml`.

## Paleta

La interfaz usa exclusivamente los tonos base del logo: azul profundo, celeste, verde, amarillo, rojo y crema, junto con blanco y negro como neutros.
